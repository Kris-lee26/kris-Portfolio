
# Kris Li｜個人網站

這是我的個人介紹網站，也是 HTML、CSS 與 GitHub Pages 的基礎實作作品。

網站主要記錄我的工作經歷、目前學習的技術，以及實作練習成果。

## 網站內容

- 關於我：個人背景與跨領域學習歷程
- 學習技能：Linux、Python、HTML/CSS、Git 與 GitHub 等基礎技術
- 學習與實作：Linux 系統管理、GitHub Actions QA 初步設定及個人網頁製作
- 聯絡方式：GitHub 個人頁面

## 使用技術

- HTML5：建立網站內容與結構
- CSS3：設計網站外觀與版面
- RWD：支援電腦與手機瀏覽
- Git / GitHub：管理程式碼與版本紀錄
- GitHub Pages：公開發布靜態網站

## 專案檔案

- `index.html`：網站首頁
- `style.css`：網站樣式與 RWD 設定
- `README.md`：專案說明文件

## 如何瀏覽

網站發布完成後，可以透過 GitHub Pages 網址直接瀏覽。

也可以下載專案檔案，在電腦上使用瀏覽器開啟 `index.html`。

## 專案狀態

目前為個人網站初始版本，已完成 HTML/CSS 與基本 RWD 排版。

這是學習階段的實作作品，後續將隨著學習進度持續更新。
